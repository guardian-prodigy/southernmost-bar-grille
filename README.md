# Southernmost Bar & Grille

Production-oriented client website for Southernmost Bar & Grille in West Palm Beach, Florida.

## Included

- Immersive Three.js hero, cocktail, and billiards scenes
- CSS 3D page-turning menu book
- Full supplied menu with modifiers and pricing
- Read-only public menu plus QR-activated table ordering
- Persistent guest tab, server assignment, service requests, tipping, and closeout flows
- Pickup, dine-in, billiards-station, and Uber Eats delivery paths
- Reservations, events, legal policies, accessibility, PWA metadata, QR landing pages, and SEO files

## Local development

```bash
python -m http.server 4173
```

Then open `http://localhost:4173/`.

## Validation

```bash
npm run check
```
