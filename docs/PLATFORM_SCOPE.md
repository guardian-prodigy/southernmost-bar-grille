# Platform Scope

## Implemented in the deployed browser experience

- Multi-page guest and operations information architecture
- Customer modes for browse, dine-in, pickup and delivery
- Full menu search, filters, imagery, availability and modifiers
- Touch and button-controlled illustrated menu book
- QR location routes and table-context preservation
- Guest verification and tab authorization interface
- Group members, item ownership, order rounds and repeat-round controls
- Service requests and preparation status
- Split-by-guest and whole-balance closeout interface
- On-device, menu-aware Island Guide without an API key
- Events, sports, reservations, billiards waitlist and private-event leads
- Loyalty and gift cards
- Staff floor, kitchen, bar, service and open-tab views
- Manager menu, event, lead and operations controls
- Progressive Three.js scenes, reduced-motion handling and mobile fallbacks
- PWA caching and network-first application updates

## Requires client-approved providers or data

- Original vector logo package and approved venue photography
- Confirmed phone, email, social accounts, parking and accessibility details
- POS and payment provider integration
- Processor-backed tab preauthorization and wallet checkout
- SMS verification and transactional messaging
- Real staff authentication and permissions
- Server-authoritative menu, tax and availability data
- Kitchen and bar routing
- Reservation, gift-card and loyalty providers
- Live sports schedule and event calendar data
- Monitoring, backups, audit logging and security review
